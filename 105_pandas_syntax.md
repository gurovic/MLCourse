# Синтаксис pandas — мышление в стиле DataFrame

## Введение: Почему pandas выглядит непривычно?

Если вы пришли в pandas из чистого Python, его синтаксис может показаться странным и магическим. Выражения вроде df[df['age'] > 30]['salary'].mean() не похожи на всё, что вы видели раньше. Это не случайность. Библиотека pandas не просто добавляет новые функции — она вводит новую парадигму для работы с данными.

Ключ к пониманию синтаксиса pandas — осознать, что его основная структура данных, DataFrame, — это не просто список списков или словарь. Это таблица с индексированными строками и столбцами, и операции над ней часто векторизованы. Это значит, что действия применяются сразу ко всей серии данных, а не к отдельным элементам в цикле. Такой подход не только выразителен, но и невероятно эффективен благодаря оптимизации под капотом.

## 1. Квадратные скобки []: Многофункциональный инструмент

В обычном Python квадратные скобки используются для доступа к элементам списка или словаря по индексу/ключу. В pandas они приобретают несколько новых смыслов в зависимости от контекста.

Одиночные скобки df['column_name']

· Что это? Доступ к столбцу. Возвращается объект Series.
· Аналог в Python: dict['key'].
· Важно: Это единственный безопасный способ обратиться к столбцу, если его имя содержит пробелы или спецсимволы. Например, df['2023 Sales'].

Одиночные скобки со списком df[['col1', 'col2']]

· Что это? Выбор нескольких столбцов. Обратите внимание на двойные скобки: внешние — оператор доступа, внутренние — это список.
· Возвращает: Новый DataFrame.
· Пример:

```python
# Выберем только столбцы 'name' и 'email'
sub_df = df[['name', 'email']]
```

Скобки с условием (фильтрация) df[df['age'] > 30]

· Что это? Это не доступ по индексу! Это фильтрация строк.
· Как работает? Выражение внутри скобок df['age'] > 30 возвращает Series из булевых значений (True/False). Затем этот Series передаётся в скобки df[...], и pandas возвращает только те строки, где значение True.
· Пример:

```python
# Фильтруем строки, оставляя только пользователей старше 30
adults_df = df[df['age'] > 30]
```

## 2. Доступ к атрибутам через точку df.column_name

· Что это? Альтернативный способ доступа к столбцу.
· Плюс: Удобно и быстро писать.
· Минусы:
  1. Не работает, если имя столбца содержит пробелы или совпадает с названием существующего метода (например, df.mean).
  2. Нельзя использовать для создания нового столбца (только для чтения существующего).
  · df.new_col = values # Так делать не стоит! Это сработает, но может привести к неожиданному поведению.
  · Правильно: df['new_col'] = values

Рекомендация: Для безопасности и ясности кода предпочтительнее использовать скобочную нотацию df['col'].

## 3. Методы .loc и .iloc: осознанный доступ по индексам

Это самые мощные и явные инструменты для выборки данных в pandas. Они созданы, чтобы избежать двусмысленности.

.loc — location-based indexing

Выборка по меткам (labels) индекса и/или именам столбцов.

· Синтаксис: df.loc[строки, столбцы]
· Примеры:

```python
df.loc[5, 'name']          # Ячейка на пересечении строки с меткой 5 и столбца 'name'
df.loc[5:10, 'name']       # Срезы в .loc ВКЛЮЧАЮТ последний элемент (10)
df.loc[df['age'] > 30, ['name', 'email']] # Комбинация фильтра и выбора столбцов
# Выбор всех строк (:), но только конкретных столбцов
df.loc[:, ['name', 'email']]
```

.iloc — integer-location-based indexing

Выборка по целочисленным позициям (как в списке Python).

· Синтаксис: df.iloc[строки, столбцы]
· Примеры:

```python
df.iloc[0, 1]        # Первая строка, второй столбец (позиции с 0)
df.iloc[0:5, 1:3]    # Срезы в .iloc, как в Python, НЕ включают последний элемент (5-я строка и 3-й столбец не войдут)
df.iloc[:, [0, 2]]   # Все строки, первый и третий столбец
```

Правило большого пальца: Хотите выбрать данные по смыслу (как они подписаны) — используйте .loc. Хотите выбрать по физическому положению в таблице — используйте .iloc.

## 4. Цепочки методов (Method Chaining)

Синтаксис pandas поощряет объединение операций в цепочки. Это делает код компактным и читаемым, так как он описывает последовательность преобразований "от общего к частному".

· Обычный стиль (последовательный):

```python
df_filtered = df[df['department'] == 'Sales']
df_sorted = df_filtered.sort_values('salary', ascending=False)
result = df_sorted.head(5)
```

· Стиль с цепочкой методов:

```python
result = (df[df['department'] == 'Sales']   # Начинаем с исходного DataFrame
           .sort_values('salary', ascending=False) # Сортируем результат предыдущей операции
           .head(5))                        # Берем первые 5 строк от отсортированного результата
```

· Зачем использовать?
  1. Читаемость: Код читается как инструкция сверху вниз.
  2. Экономия памяти: Не создаются промежуточные переменные.
  3. Ясность: Понятно, что каждая следующая операция применяется к результату предыдущей.
· Подводный камень: Отладка может быть сложнее. Если цепочка упадет с ошибкой, сложнее понять, на каком именно шаге.

## 5. Выражения в виде строк с query() и eval()

Pandas предлагает альтернативные способы записи операций, которые могут сделать код чище и лаконичнее.

Метод .query()

Позволяет выразить условие фильтрации в виде строки.

```python
# Вместо df[df['age'] > 30]
df.query('age > 30')

# Удобно для сложных условий
df.query('age > 30 and department == "Sales"')
```

Метод .eval()

Позволяет вычислять выражения над столбцами (например, создать новый столбец) более эффективно для больших DataFrame.

```python
# Вместо df['new_col'] = df['col1'] + df['col2']
df.eval('new_col = col1 + col2', inplace=True)
```

Эти методы не являются строго необходимыми, но могут сделать ваш код более декларативным.

## Заключение: Как мыслить в стиле pandas

1. Забудьте на время о циклах. Ваша первая мысль для фильтрации или преобразования данных не должна быть о for. Ищите векторный метод.
2. Смотрите на данные как на таблицу. Вам нужны строки или столбцы? Для точной выборки используйте .loc/.iloc.
3. Стройте цепочки. Преобразуйте данные, передавая результат одной операции на вход следующей. Это естественный поток для pandas.
4. Читайте код слева направо и сверху вниз. Цепочка методов читается именно так: "возьми DataFrame, отсортируй его, затем возьми топ-5".

Синтаксис pandas — это уникальный язык операций над табличными данными, встроенный в Python. Потратив время на его изучение, вы получите в свое распоряжение невероятно мощный и выразительный инструмент для анализа данных.
