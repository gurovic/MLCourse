### 🟢 Базовый уровень (Основы Polars)

1. **Создание и базовые операции**  
   Создайте DataFrame со следующими столбцами:
   - `student_id`: [101, 102, 103, 104, 105]
   - `exam_score`: [85, 92, 78, 95, 88]
   - `homework_score`: [90, 85, 82, 98, 91]
   
   Выполните:
   - Добавьте столбец `final_grade` как среднее взвешенное: 70% экзамен + 30% домашнее задание
   - Отфильтруйте студентов с итоговой оценкой выше 87
   - Отсортируйте по `final_grade` в порядке убывания

2. **Работа с типами данных**  
   Загрузите CSV-файл с данными о продажах. Преобразуйте:
   - Столбец `date` из строки в тип Date
   - Столбец `category` в Categorical для экономии памяти
   - Столбец `quantity` из Float в Int32
   
   Выведите информацию о типах и размере DataFrame до и после преобразования.

3. **Группировка и агрегация**  
   Используя данные интернет-магазина:
   - Сгруппируйте заказы по `customer_id`
   - Для каждого клиента вычислите: общую сумму покупок, среднюю сумму заказа, количество заказов
   - Найдите топ-3 клиентов по общей сумме покупок
   - Визуализируйте распределение количества заказов на клиента

### 🟡 Продвинутый уровень (Оптимизация и сложные операции)

4. **Lazy API и оптимизация запросов**  
   Работа с большим датасетом логов веб-сервера:
   - Используйте `scan_csv` для ленивой загрузки
   - Отфильтруйте только GET-запросы со статусом 200
   - Сгруппируйте по часам и подсчитайте количество запросов
   - Изучите план запроса с помощью `.explain()` до и после оптимизации
   - Сравните время выполнения Eager vs Lazy подходов

5. **Оконные функции**  
   Датасет продаж по месяцам для разных продуктов:
   - Для каждого продукта вычислите ранг продаж внутри своей категории
   - Добавьте столбец с процентом от максимальных продаж в категории
   - Вычислите скользящее среднее продаж за 3 месяца
   - Определите месяцы, где продажи выше среднего по категории

6. **Сложные условные выражения**  
   Датасет пользователей соцсети:
   - Создайте сегменты пользователей на основе:
     * `activity_score` (low <30, medium 30-70, high >70)
     * `days_since_registration` (new <30, regular 30-365, veteran >365)
   - Используйте `pl.when().then().otherwise()` для создания колонки `user_segment`
   - Постройте матрицу сегментов и посчитайте количество пользователей в каждом
   - Вычислите средний `revenue` для каждого сегмента

### 🔴 Экспертный уровень (Продвинутые техники)

7. **Множественные Join с оптимизацией**  
   Три таблицы: `orders`, `customers`, `products`:
   - Выполните цепочку join'ов для получения полной информации о заказах
   - Используйте разные типы join (inner, left, cross) в зависимости от связей
   - Обработайте дубликаты с помощью оконных функций и `rank()`
   - Сравните производительность с аналогичной операцией в pandas
   - Оптимизируйте запрос, используя предварительную фильтрацию

8. **Streaming mode для больших данных**  
   Симулируйте обработку лог-файлов, не помещающихся в память:
   - Создайте синтетический датасет (>2GB) с логами транзакций
   - Используйте `collect(streaming=True)` для обработки
   - Вычислите статистики: медиану суммы транзакций, 95-й перцентиль
   - Найдите аномальные транзакции (>3 стандартных отклонений)
   - Замерьте пиковое потребление памяти

9. **Временные ряды и даты**  
   Датасет биржевых котировок:
   - Создайте признаки из временных меток: день недели, час, квартал
   - Вычислите доходность (процентное изменение цены) для разных таймфреймов (1h, 1d, 1w)
   - Реализуйте индикатор: экспоненциальная скользящая средняя (EMA)
   - Добавьте столбец с датой предыдущей торговой сессии (пропуская выходные)
   - Агрегируйте данные по неделям с помощью `groupby_dynamic`

### 💡 Советы по выполнению заданий

1. **Всегда используйте Lazy API для больших данных** — это даёт максимальную оптимизацию
2. **Изучайте explain()** — понимание плана запроса помогает писать эффективный код
3. **Не бойтесь экспериментировать** — Polars часто находит оптимизации, о которых вы не думали
4. **Используйте профилирование** — замеряйте время и память для понимания узких мест
5. **Думайте выражениями** — избегайте циклов и apply, используйте векторизованные операции
