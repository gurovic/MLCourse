Задачи к главе: Эффективная обработка данных

🟢 Базовый уровень

Задача 1: Создание простого Dataset

Цель: Научиться создавать базовый Dataset для табличных данных

Требования:

1. Создайте класс StudentDataset для данных о студентах
2. Данные: 1000 студентов, каждый имеет 5 признаков (оценки по предметам) и целевую переменную (сдал/не сдал)
3. Реализуйте методы __len__ и __getitem__
4. Добавьте метод для вывода статистики о данных

Критерии успеха:

· Dataset корректно возвращает данные по индексу
· Правильно вычисляется количество примеров
· Статистика включает информацию о размере данных и распределении классов

---

Задача 2: Работа с DataLoader

Цель: Освоить создание и использование DataLoader

Требования:

1. Создайте Dataset из предыдущей задачи
2. Создайте три DataLoader с разными параметрами:
   · Для обучения: batch_size=32, shuffle=True
   · Для валидации: batch_size=32, shuffle=False
   · Для теста: batch_size=64, shuffle=False
3. Напишите функцию, которая проходит по DataLoader и выводит информацию о батчах

Критерии успеха:

· DataLoader корректно создает батчи
· Разные параметры применяются правильно
· Функция показывает размеры батчей и распределение меток

---

Задача 3: Сравнение стратегий обучения

Цель: Понимать разницу между разными подходами к батчам

Требования:

1. На одних и тех же данных обучите три модели:
   · С batch_size=1 (стохастический градиентный спуск)
   · С batch_size=32 (мини-батч)
   · С batch_size=1000 (полный батч)
2. Сравните:
   · Скорость сходимости (график loss)
   · Время обучения на эпоху
   · Финальную точность
3. Сделайте вывод о преимуществах каждого метода

Критерии успеха:

· Правильная реализация всех трех стратегий
· Наглядные графики сравнения
· Обоснованные выводы

🟡 Продвинутый уровень

Задача 4: Dataset с преобразованиями

Цель: Научиться добавлять предобработку данных в Dataset

Требования:

1. Создайте AugmentedDataset, который:
   · Нормализует признаки (приводит к mean=0, std=1)
   · С вероятностью 50% добавляет гауссовский шум к данным
   · Имеет параметры для настройки уровня шума
2. Реализуйте split-метод для разделения на train/val
3. Сравните обучение с обычным Dataset и AugmentedDataset

Критерии успеха:

· Преобразования применяются корректно
· Нормализация работает правильно (проверьте статистики)
· Аугментация улучшает обобщающую способность модели

Задача 5: Оптимизация загрузки данных

Цель: Научиться ускорять загрузку данных

Требования:

1. Создайте большой Dataset (минимум 50,000 примеров)
2. Измерьте скорость загрузки с разными num_workers (0, 2, 4)
3. Проанализируйте влияние на:
   · Время загрузки одного батча
   · Общее время эпохи
   · Использование CPU
4. Определите оптимальное значение num_workers для вашей системы

Критерии успеха:

· Корректные измерения производительности
· Графики зависимости времени от num_workers
· Практические рекомендации по настройке

Задача 6: Кастомный DataLoader

Цель: Создать специализированный DataLoader для специфичных данных

Требования:

1. Создайте Dataset для временных рядов:
   · Каждый пример - последовательность из 10 временных шагов
   · Целевая переменная - следующее значение
2. Реализуйте DataLoader, который:
   · Создает батчи с учетом временной зависимости
   · Поддерживает разные стратегии формирования последовательностей
   · Обрабатывает краевые случаи
3. Сравните с обычным DataLoader

Критерии успеха:

· DataLoader корректно формирует последовательности
· Временные зависимости не нарушаются
· Реализация эффективна по памяти

🔴 Экспертный уровень

Задача 7: Dataset для больших данных

Цель: Научиться работать с данными, которые не помещаются в память

Требования:

1. Создайте DiskDataset, который:
   · Хранит данные на диске в нескольких файлах
   · Загружает в память только текущий батч
   · Поддерживает кэширование часто используемых данных
2. Реализуйте механизм префетчинга (предзагрузки следующего батча)
3. Сравните производительность с обычным Dataset на данных размером 1+ ГБ

Критерии успеха:

· Dataset работает с данными больше доступной памяти
· Префетчинг ускоряет загрузку данных
· Эффективное использование дискового I/O

Критерии успеха:
