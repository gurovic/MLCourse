## 🟢 Базовый уровень: Что такое MLP?

### 1.1 Архитектура многослойного перцептрона

**MLP (Multilayer Perceptron)** — это полносвязная нейронная сеть, где каждый нейрон одного слоя связан со всеми нейронами следующего слоя.

**Компоненты MLP:**
- **Входной слой** — принимает данные (признаки)
- **Скрытые слои** — извлекают признаки и паттерны
- **Выходной слой** — выдает предсказание

```python
# Простейшая MLP с одним скрытым слоем
class SimpleMLP(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(SimpleMLP, self).__init__()
        self.fc1 = nn.Linear(input_size, hidden_size)  # Входной -> Скрытый
        self.relu = nn.ReLU()                           # Функция активации
        self.fc2 = nn.Linear(hidden_size, output_size) # Скрытый -> Выходной
    
    def forward(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x

# Создание модели: 2 входа -> 10 нейронов -> 1 выход
model = SimpleMLP(input_size=2, hidden_size=10, output_size=1)
print(model)
```

### 1.2 Функции активации

Без функций активации MLP была бы просто линейной моделью. Функции активации добавляют нелинейность.

**Почему это важно?** 
Без активаций: `f(x) = W2 * (W1 * x + b1) + b2 = (W2 * W1) * x + (W2 * b1 + b2)` — это просто одна линейная функция! 
Многослойность теряет смысл. Функции активации позволяют MLP приближать **любую непрерывную функцию** (универсальная теорема аппроксимации).

**ReLU (Rectified Linear Unit):**
```python
def relu(x):
    return np.maximum(0, x)

x = np.linspace(-3, 3, 100)
plt.plot(x, relu(x))
plt.title('ReLU')
plt.grid(True)
plt.show()
```

**Sigmoid:**
```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

plt.plot(x, sigmoid(x))
plt.title('Sigmoid')
plt.grid(True)
plt.show()
```

**Tanh:**
```python
def tanh(x):
    return np.tanh(x)

plt.plot(x, tanh(x))
plt.title('Tanh')
plt.grid(True)
plt.show()
```

### 1.3 Первая модель на MNIST

MNIST — классический датасет рукописных цифр (0-9). 60,000 примеров для обучения, 10,000 для теста. Каждое изображение — 28x28 пикселей в градациях серого.

```python
from torchvision import datasets, transforms

# Загрузка данных
transform = transforms.Compose([transforms.ToTensor()])
train_dataset = datasets.MNIST(root='./data', train=True, download=True, transform=transform)
test_dataset = datasets.MNIST(root='./data', train=False, transform=transform)

# DataLoader для батчей
train_loader = torch.utils.data.DataLoader(train_dataset, batch_size=64, shuffle=True)
test_loader = torch.utils.data.DataLoader(test_dataset, batch_size=1000)

# Модель для MNIST (28x28=784 входа, 10 классов)
class MNISTClassifier(nn.Module):
    def __init__(self):
        super(MNISTClassifier, self).__init__()
        self.fc1 = nn.Linear(784, 128)
        self.relu1 = nn.ReLU()
        self.fc2 = nn.Linear(128, 64)
        self.relu2 = nn.ReLU()
        self.fc3 = nn.Linear(64, 10)
    
    def forward(self, x):
        x = x.view(-1, 784)  # Преобразуем 28x28 в вектор 784
        x = self.relu1(self.fc1(x))
        x = self.relu2(self.fc2(x))
        x = self.fc3(x)
        return x

model = MNISTClassifier()
```

## 🟡 Продвинутый уровень: Обучение MLP

### 2.1 Процесс обучения

```python
# Функция потерь и оптимизатор
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# Обучение
def train_epoch(model, loader, criterion, optimizer):
    model.train()
    total_loss = 0
    for batch_idx, (data, target) in enumerate(loader):
        optimizer.zero_grad()           # Обнуляем градиенты
        output = model(data)            # Прямой проход
        loss = criterion(output, target) # Вычисляем loss
        loss.backward()                 # Обратное распространение
        optimizer.step()                # Обновляем веса
        total_loss += loss.item()
    return total_loss / len(loader)

# Оценка
def evaluate(model, loader):
    model.eval()
    correct = 0
    with torch.no_grad():
        for data, target in loader:
            output = model(data)
            pred = output.argmax(dim=1)
            correct += pred.eq(target).sum().item()
    return 100. * correct / len(loader.dataset)

# Цикл обучения
for epoch in range(10):
    train_loss = train_epoch(model, train_loader, criterion, optimizer)
    test_acc = evaluate(model, test_loader)
    print(f'Epoch {epoch+1}: Loss={train_loss:.4f}, Accuracy={test_acc:.2f}%')
```

### 2.2 Глубина vs Ширина

**Глубокие сети** (много слоев):
- Извлекают иерархию признаков (каждый слой — своя "абстракция")
- Могут переобучаться
- Требуют осторожной инициализации весов

**Широкие сети** (много нейронов в слое):
- Больше параметров в одном слое
- Требуют больше данных
- Обычно проще в обучении

**Практический совет:** Начинайте с 2-3 слоев по 64-128 нейронов. Углубляйте только если видите, что модель недообучается.


### 2.3 Выбор функции активации

| Функция | Плюсы | Минусы | Применение |
|---------|-------|---------|------------|
| **ReLU** | Быстрая, не насыщается | "Мертвые нейроны" | Скрытые слои (по умолчанию) |
| **Leaky ReLU** | Решает проблему мертвых нейронов | Небольшой эффект | Скрытые слои |
| **Sigmoid** | Выход 0-1 | Затухающие градиенты | Выходной слой (бинарная классификация) |
| **Tanh** | Выход -1...1, центрирован | Затухающие градиенты | Скрытые слои (RNN) |
| **Softmax** | Вероятностное распределение | - | Выходной слой (многоклассовая классификация) |

```python
# Пример с разными активациями
class FlexibleMLP(nn.Module):
    def __init__(self, activation='relu'):
        super(FlexibleMLP, self).__init__()
        self.fc1 = nn.Linear(784, 128)
        self.fc2 = nn.Linear(128, 64)
        self.fc3 = nn.Linear(64, 10)
        
        if activation == 'relu':
            self.act = nn.ReLU()
        elif activation == 'tanh':
            self.act = nn.Tanh()
        elif activation == 'sigmoid':
            self.act = nn.Sigmoid()
    
    def forward(self, x):
        x = x.view(-1, 784)
        x = self.act(self.fc1(x))
        x = self.act(self.fc2(x))
        x = self.fc3(x)
        return x
```

## 🔴 Экспертный уровень: Продвинутые техники

### 3.1 Residual Connections в MLP

Остаточные связи помогают обучать глубокие сети.

```python
class ResidualBlock(nn.Module):
    def __init__(self, size):
        super(ResidualBlock, self).__init__()
        self.fc1 = nn.Linear(size, size)
        self.fc2 = nn.Linear(size, size)
        self.relu = nn.ReLU()
    
    def forward(self, x):
        residual = x
        out = self.relu(self.fc1(x))
        out = self.fc2(out)
        out += residual  # Остаточная связь
        out = self.relu(out)
        return out

class DeepResidualMLP(nn.Module):
    def __init__(self):
        super(DeepResidualMLP, self).__init__()
        self.fc_in = nn.Linear(784, 128)
        self.residual_blocks = nn.Sequential(*[ResidualBlock(128) for _ in range(5)])
        self.fc_out = nn.Linear(128, 10)
    
    def forward(self, x):
        x = x.view(-1, 784)
        x = nn.ReLU()(self.fc_in(x))
        x = self.residual_blocks(x)
        x = self.fc_out(x)
        return x
```

### 3.3 Нелинейные границы решений

MLP может создавать сложные нелинейные границы решений, в отличие от линейных моделей. Это позволяет решать задачи, где классы не разделимы прямой линией.

```python
# Визуализация границ решений MLP
def plot_decision_boundary(model, X, y):
    x_min, x_max = X[:, 0].min() - 0.5, X[:, 0].max() + 0.5
    y_min, y_max = X[:, 1].min() - 0.5, X[:, 1].max() + 0.5
    xx, yy = np.meshgrid(np.linspace(x_min, x_max, 100),
                         np.linspace(y_min, y_max, 100))
    
    Z = model(torch.FloatTensor(np.c_[xx.ravel(), yy.ravel()]))
    Z = torch.sigmoid(Z).detach().numpy().reshape(xx.shape)
    
    plt.contourf(xx, yy, Z, alpha=0.8, cmap='RdYlBu')
    plt.scatter(X[:, 0], X[:, 1], c=y, edgecolors='k', cmap='RdYlBu')
    plt.title('Граница решений MLP')
    plt.show()

# Пример на данных moons (полумесяцы — классическая нелинейная задача)
X, y = make_moons(n_samples=200, noise=0.1)
```

## 💎 Заключение

**Ключевые принципы MLP:**
1. **Полносвязность** — каждый нейрон связан со всеми нейронами следующего слоя
2. **Нелинейность** — функции активации позволяют моделировать сложные зависимости
3. **Глубина** — многослойность извлекает иерархию признаков

**Когда использовать MLP:**
- ✅ Табличные данные (признаки независимы)
- ✅ Задачи классификации и регрессии
- ✅ Когда нет пространственной/временной структуры
- ✅ Нужны сложные нелинейные зависимости (которые не уловит линейная модель)

**Когда НЕ использовать:**
- ❌ Изображения (используйте CNN — учтет пространственную структуру)
- ❌ Временные ряды/текст (используйте RNN/Transformer — учтет последовательность)
- ❌ Графы (используйте GNN — учтет связи между узлами)
- ❌ Мало данных и простые зависимости (лучше использовать Random Forest или линейные модели)
- ❌ Нужна интерпретируемость (лучше деревья решений или линейные модели)

**Лучшие практики:**
- Начинайте с малых моделей (2-3 слоя по 64-128 нейронов)
- ReLU — активация по умолчанию для скрытых слоев
- Используйте Batch Normalization и Dropout для регуляризации
- Мониторьте переобучение (train vs validation loss)
- Не забывайте про масштабирование входных данных (StandardScaler)
- Пробуйте разные learning rate (начните с 0.001 для Adam)
