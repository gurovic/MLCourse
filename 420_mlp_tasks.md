# Задачи по главе "Полносвязные нейронные сети (MLP)"

## 🟢 Базовый уровень

### Задача 1: Расчет параметров и потребления памяти
Создайте MLP для обработки изображений MNIST (28×28 пикселей = 784 признака) для классификации 10 цифр.
1. Рассчитайте количество параметров для архитектуры [784, 128, 64, 10]
2. Оцените объем памяти (в МБ) для хранения весов модели в формате float32
3. Если каждый параметр заменить на float16, на сколько уменьшится потребление памяти?
4. Создайте функцию, которая автоматически рассчитывает параметры для любой архитектуры

### Задача 2: Анализ влияния функций активации
Создайте три идентичные MLP-модели для бинарной классификации, отличающиеся только функцией активации:
1. ReLU в скрытых слоях
2. Sigmoid в скрытых слоях  
3. Tanh в скрытых слоях

Обучите их на одних данных и проанализируйте:
- Скорость сходимости (на какой эпохе достигается 95% точности)
- Финальную точность на тестовой выборке
- Графики loss для каждой функции активации
- Объясните различия в результатах

### Задача 3: Понимание размерностей данных
Даны данные: 1000 примеров, каждый содержит 50 признаков. Нужно предсказать 3 класса.
1. Какой должна быть размерность тензора X_train?
2. Какой должна быть размерность тензора y_train?
3. Если использовать batch_size=32, как будут выглядеть размерности в одном батче?
4. Напишите код, который автоматически проверяет согласованность размерностей перед обучением

## 🟡 Средний уровень

### Задача 1: Регуляризация и борьба с переобучением
Возьмите датасет с большим количеством признаков (например, 100+) и малым количеством примеров (500).
1. Обучите обычную MLP и наблюдайте переобучение
2. Добавьте L2-регуляризацию (weight_decay) и подберите оптимальный коэффициент
3. Добавьте Dropout слои и подберите оптимальную вероятность
4. Сравните результаты трех подходов по метрикам:
   - Точность на обучающей и тестовой выборках
   - Разница между train/test accuracy
   - Время обучения

### Задача 2: Автоматический подбор гиперпараметров
Создайте систему автоматического подбора гиперпараметров для MLP:
1. Реализуйте grid search для подбора:
   - Количества скрытых слоев (1-3)
   - Количества нейронов в слоях (16, 32, 64, 128)
   - Learning rate (0.1, 0.01, 0.001)
   - Функции активации (ReLU, Tanh)

2. Для каждой комбинации:
   - Обучите модель
   - Оцените на валидационной выборке
   - Сохраните результаты

3. Выведите таблицу с топ-5 лучших комбинаций параметров
4. Протестируйте лучшую модель на тестовой выборке

### Задача 3: Мультиклассовая классификация на реальных данных
Возьмите датасет Iris (3 класса, 4 признака) или Wine (3 класса, 13 признаков):
1. Разделите данные на train/val/test (60/20/20)
2. Постройте MLP для классификации 3 классов
3. Используйте матрицу ошибок (confusion matrix) для анализа результатов
4. Рассчитайте precision, recall, F1-score для каждого класса
5. Визуализируйте предсказания модели в 2D (используя PCA или t-SNE для уменьшения размерности)

## 🔴 Продвинутый уровень

### Задача 1: Оптимизация архитектуры с Residual Connections
Создайте очень глубокую MLP (8+ слоев) для сложной задачи:
1. Реализуйте базовую глубокую сеть без остаточных связей
2. Реализуйте сеть той же глубины с Residual Connections
3. Сравните:
   - Скорость обучения (количество эпох до сходимости)
   - Градиенты (норму градиентов в разных слоях)
   - Финальную точность
   - Устойчивость к различным learning rates

4. Проанализируйте, в каких случаях остаточные связи помогают больше всего

### Задача 2: Диагностика и отладка проблемной модели
Дана MLP, которая не обучается (accuracy ~50% для бинарной классификации):
1. Проведите полную диагностику:
   - Проверьте распределение активаций в каждом слое
   - Проверьте распределение градиентов
   - Проверьте инициализацию весов
   - Проверьте данные (нормализацию, наличие выбросов)

2. Реализуйте инструменты для автоматической диагностики:
   - Визуализация градиентов по слоям
   - Мониторинг активаций (dead ReLU problem)
   - Отслеживание изменения весов

3. Предложите и реализуйте минимум 3 исправления

### Задача 3: Создание модульной MLP-библиотеки
Создайте библиотеку для быстрого прототипирования MLP:
1. Реализуйте класс ModularMLP, который позволяет:
   - Легко добавлять/удалять слои
   - Выбирать функции активации для каждого слоя
   - Добавлять BatchNorm/Dropout после любого слоя
   - Сохранять/загружать архитектуру

2. Добавьте автоматическое логирование:
   - Loss и accuracy на каждой эпохе
   - Градиенты весов
   - Время выполнения

3. Реализуйте callback-систему для:
   - Early stopping
   - Learning rate scheduling
   - Сохранения лучшей модели

4. Протестируйте библиотеку на 3 разных датасетах

## 💡 Подсказки:

### Для базового уровня:
- Используйте `torch.nn.Linear` для создания слоев
- Помните: параметры = (input_size × output_size + output_size) для каждого слоя
- float32 занимает 4 байта, float16 - 2 байта

### Для среднего уровня:
- Используйте `sklearn.model_selection` для разделения данных
- Для grid search можно использовать циклы или `itertools.product`
- Матрицу ошибок можно построить с помощью `sklearn.metrics.confusion_matrix`

### Для продвинутого уровня:
- Для отслеживания градиентов используйте `.register_backward_hook()`
- Для визуализации используйте `matplotlib` или `tensorboard`
- Документируйте код с помощью docstrings и комментариев
