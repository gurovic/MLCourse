### **Задача 7: Residual Connections**

**Условие:** Реализуйте и сравните очень глубокую сеть с/без residual connections.

**Требования:**
1. Реализуйте `ResidualBlock`:
   ```python
   class ResidualBlock(nn.Module):
       def forward(self, x):
           residual = x
           out = self.fc1(x)
           out = self.relu(out)
           out = self.fc2(out)
           out += residual  # Skip connection
           out = self.relu(out)
           return out
   ```

2. Постройте две глубокие сети (10 слоев):
   - Обычная MLP
   - MLP с residual connections

3. Обучите обе и сравните:
   - Способность к обучению (сходится ли обычная MLP?)
   - Финальную accuracy
   - Градиенты на первых слоях

**Вопрос:** Почему residual connections решают проблему затухающих градиентов?
