### **Задачи: Генеративные модели для текста**

**Цель:** Научиться использовать и fine-tune GPT, T5 для генерации текста.

---

## 🟢 Базовый уровень

### **Задача 1: Text Generation с GPT-2**

Используйте GPT-2 для генерации текста с разными параметрами.

**Эксперименты:** temperature=[0.3, 0.7, 1.0, 1.5], top_k=[10, 50, 100].

**Требования:** Проанализируйте влияние параметров на качество и разнообразие текста.

---

### **Задача 2: Summarization с T5**

Используйте T5 для автоматического summarization статей.

**Требования:** Оцените качество (ROUGE score), сравните разные размеры T5 (small/base/large).

---

### **Задача 3: Сравнение Sampling Strategies**

Сравните greedy, top-k, top-p, beam search для генерации текста.

---

## 🟡 Продвинутый уровень

### **Задача 4: Fine-tuning GPT-2**

Fine-tune GPT-2 на специфическом корпусе (код, поэзия, диалоги).

**Требования:** Обучите, сгенерируйте примеры, оцените качество вручную.

---

### **Задача 5: Conditional Text Generation**

Реализуйте controlled generation с промптами и префиксами.

---

## 🔴 Экспертный уровень

### **Задача 6: Dialogue System с GPT**

Создайте chatbot используя fine-tuned GPT-2.

---

### **Задача 7: Few-shot Learning**

Используйте GPT-3 API (или GPT-2) для few-shot learning задач.
