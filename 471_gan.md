## 🟢 Базовый уровень: GAN основы

### 1.1 Что такое GAN?

**GAN = Generative Adversarial Network**

**Идея:** Две нейросети играют в игру:
- **Generator (G):** Создает fake данные из шума
- **Discriminator (D):** Отличает real от fake

```
Random noise → Generator → Fake image
                               ↓
Real image → Discriminator → Real or Fake?
```

**Процесс обучения:**
1. D учится отличать real от fake
2. G учится обманывать D
3. Они улучшаются вместе → G создает реалистичные данные

---

### 1.2 Математическая формулировка

**Цель:** Minimax игра

```
min_G max_D V(D, G) = E[log D(x)] + E[log(1 - D(G(z)))]
```

- **D максимизирует:** правильно классифицирует real и fake
- **G минимизирует:** обманывает D (делает D(G(z)) близким к 1)

---

### 1.3 Простой GAN для MNIST

```python
class Generator(nn.Module):
    def __init__(self, latent_dim=100, output_dim=784):
        super().__init__()
        self.model = nn.Sequential(
            nn.Linear(latent_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 512),
            nn.ReLU(),
            nn.Linear(512, output_dim),
            nn.Tanh()  # выход в [-1, 1]
        )
    
    def forward(self, z):
        return self.model(z)

class Discriminator(nn.Module):
    def __init__(self, input_dim=784):
        super().__init__()
        self.model = nn.Sequential(
            nn.Linear(input_dim, 512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 1),
            nn.Sigmoid()  # вероятность real
        )
    
    def forward(self, x):
        return self.model(x)
```

### 1.4 Training Loop

```python
latent_dim = 100
generator = Generator(latent_dim)
discriminator = Discriminator()

criterion = nn.BCELoss()
g_optimizer = optim.Adam(generator.parameters(), lr=2e-4)
d_optimizer = optim.Adam(discriminator.parameters(), lr=2e-4)

for epoch in range(100):
    for real_images, _ in train_loader:
        batch_size = real_images.size(0)
        real_images = real_images.view(batch_size, -1)
        real_labels = torch.ones(batch_size, 1)
        fake_labels = torch.zeros(batch_size, 1)
        
        # === Train Discriminator ===
        # На real данных
        d_real = discriminator(real_images)
        d_real_loss = criterion(d_real, real_labels)
        
        # На fake данных
        z = torch.randn(batch_size, latent_dim)
        fake_images = generator(z)
        d_fake = discriminator(fake_images.detach())
        d_fake_loss = criterion(d_fake, fake_labels)
        
        # Обновляем D
        d_loss = d_real_loss + d_fake_loss
        d_optimizer.zero_grad()
        d_loss.backward()
        d_optimizer.step()
        
        # === Train Generator ===
        z = torch.randn(batch_size, latent_dim)
        fake_images = generator(z)
        d_fake = discriminator(fake_images)
        g_loss = criterion(d_fake, real_labels)  # хотим, чтобы D думал, что fake = real
        
        g_optimizer.zero_grad()
        g_loss.backward()
        g_optimizer.step()
```

## 🟡 Продвинутый уровень: Проблемы GAN

### 2.1 Mode Collapse

**Проблема:** Generator генерирует только несколько режимов (modes) данных.

**Пример:** Вместо всех цифр 0-9, генерирует только 1, 5, 7.

**Решение:**
- Minibatch discrimination
- Unrolled GAN
- Использовать более стабильные архитектуры (DCGAN, WGAN)

---

### 2.2 Training Instability

**Проблемы:**
- D слишком сильный → G не учится
- G слишком сильный → D не дает полезного градиента
- Oscillations, не сходится

**Решения:**
- Балансировать обучение D и G
- One-sided label smoothing
- Использовать правильные архитектуры и hyperparameters

---

### 2.3 Tips для стабильного обучения

1. **LeakyReLU** вместо ReLU в D
2. **BatchNorm** в обеих сетях (кроме output D и input G)
3. **Adam optimizer** с β1=0.5
4. **Label smoothing:** real labels = 0.9 вместо 1.0
5. **Separate batches** для D и G
6. **Learning rate:** 0.0002 для обеих

### 3.2 Fréchet Inception Distance (FID)

Измеряет расстояние между распределениями real и fake изображений.

```
FID = ||μ_real - μ_fake||² + Tr(Σ_real + Σ_fake - 2√(Σ_real Σ_fake))
```

**Низкий FID** = более похожие распределения = лучше

## 🔴 Экспертный уровень: Variations

### 4.1 Conditional GAN (cGAN)

Генерация с условием (например, класс цифры).

```python
class ConditionalGenerator(nn.Module):
    def __init__(self, latent_dim=100, num_classes=10):
        super().__init__()
        self.label_emb = nn.Embedding(num_classes, latent_dim)
        
        self.model = nn.Sequential(
            nn.Linear(latent_dim * 2, 256),  # z + label embedding
            nn.ReLU(),
            # ...
        )
    
    def forward(self, z, labels):
        label_emb = self.label_emb(labels)
        x = torch.cat([z, label_emb], dim=1)
        return self.model(x)
```
