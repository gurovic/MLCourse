## 🟢 Базовый уровень: Основы графов

### 1.1 Что такое граф?

**Граф G = (V, E)**
- **V** — множество вершин (nodes)
- **E** — множество рёбер (edges)

**Примеры:**
- Social networks (люди = nodes, дружба = edges)
- Молекулы (атомы = nodes, связи = edges)
- Citation networks (статьи = nodes, цитирования = edges)

---

### 1.2 Представление графа

**Adjacency Matrix A:**
```
A[i,j] = 1 если есть ребро между i и j
A[i,j] = 0 иначе
```

**Node Features X:**
```
X ∈ R^(n × d) где n = число вершин, d = размерность features
```

---

### 1.3 Задачи на графах

1. **Node Classification:** предсказать класс каждой вершины
2. **Link Prediction:** предсказать будущие связи
3. **Graph Classification:** классифицировать весь граф
4. **Node Clustering:** кластеризация вершин

## 🟢 Базовый уровень: Message Passing

### 2.1 Основная идея GNN

**Message Passing:** Вершина собирает информацию от соседей.

```
h_v^(k+1) = UPDATE(h_v^(k), AGGREGATE({h_u^(k) : u ∈ N(v)}))
```

- **h_v^(k)** — embedding вершины v на слое k
- **N(v)** — соседи вершины v
- **AGGREGATE** — функция агрегации (sum, mean, max)
- **UPDATE** — функция обновления (обычно нейросеть)

---

### 2.2 Простой GNN Layer

```python
class SimpleGNNLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)
    
    def forward(self, x, adj):
        """
        x: [num_nodes, in_features] - node features
        adj: [num_nodes, num_nodes] - adjacency matrix
        """
        # Aggregate: умножаем на adjacency matrix
        aggregated = torch.matmul(adj, x)  # sum of neighbors
        
        # Update: применяем linear transformation
        out = self.linear(aggregated)
        
        return F.relu(out)
```

## 🟡 Продвинутый уровень: Graph Convolutional Network (GCN)

### 3.1 GCN Layer

**Формула:**
```
H^(l+1) = σ(D̃^(-1/2) Ã D̃^(-1/2) H^(l) W^(l))
```

Где:
- **Ã = A + I** (добавляем self-loops)
- **D̃** — degree matrix
- **W** — learnable weights
- **σ** — activation function

---

### 3.2 GCN Implementation

```python
class GCNLayer(nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        self.linear = nn.Linear(in_features, out_features)
    
    def forward(self, x, adj):
        # Add self-loops
        adj = adj + torch.eye(adj.size(0))
        
        # Compute degree matrix
        degree = adj.sum(dim=1)
        degree_inv_sqrt = torch.pow(degree, -0.5)
        degree_inv_sqrt[degree_inv_sqrt == float('inf')] = 0
        
        # Normalize adjacency matrix
        D_inv_sqrt = torch.diag(degree_inv_sqrt)
        adj_normalized = D_inv_sqrt @ adj @ D_inv_sqrt
        
        # Apply GCN operation
        out = adj_normalized @ x
        out = self.linear(out)
        
        return F.relu(out)

class GCN(nn.Module):
    def __init__(self, in_features, hidden_features, num_classes):
        super().__init__()
        self.gcn1 = GCNLayer(in_features, hidden_features)
        self.gcn2 = GCNLayer(hidden_features, num_classes)
    
    def forward(self, x, adj):
        x = self.gcn1(x, adj)
        x = F.dropout(x, p=0.5, training=self.training)
        x = self.gcn2(x, adj)
        return F.log_softmax(x, dim=1)
```

## 🟡 Продвинутый уровень: Graph Attention Networks (GAT)

### 4.1 Attention для графов

**Идея:** Не все соседи одинаково важны — используем attention.

```
α_ij = attention(h_i, h_j)  # importance of node j for node i
h_i' = σ(Σ_j α_ij W h_j)
```

---

### 4.2 GAT Layer

```python
class GATLayer(nn.Module):
    def __init__(self, in_features, out_features, num_heads=1):
        super().__init__()
        self.num_heads = num_heads
        
        self.W = nn.Linear(in_features, out_features * num_heads)
        self.a = nn.Linear(2 * out_features, 1)
    
    def forward(self, x, adj):
        h = self.W(x)  # [num_nodes, out_features * num_heads]
        
        # Compute attention coefficients
        num_nodes = x.size(0)
        h_repeat = h.repeat(num_nodes, 1)
        h_concat = torch.cat([h_repeat, h.repeat_interleave(num_nodes, dim=0)], dim=1)
        
        e = F.leaky_relu(self.a(h_concat))
        e = e.view(num_nodes, num_nodes)
        
        # Mask attention using adjacency
        e = e.masked_fill(adj == 0, float('-inf'))
        
        # Attention weights
        alpha = F.softmax(e, dim=1)
        
        # Aggregate with attention
        out = torch.matmul(alpha, h)
        
        return F.elu(out)
```
