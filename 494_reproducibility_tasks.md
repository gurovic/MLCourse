# Задачи: Повторяемость экспериментов

## 🟢 Базовый уровень

### Задача 1: Простая проверка seed

Напишите функцию, которая проверяет, работает ли seed правильно.

**Требования**:
- Генерируйте 10 случайных чисел с помощью NumPy с `seed=42`
- Запустите функцию дважды
- Проверьте, что результаты идентичны
- Выведите первые 3 числа для проверки

**Ожидаемый результат**: оба запуска должны дать одинаковые числа.

### Задача 2: NumPy vs PyTorch seed

Создайте скрипт, демонстрирующий разницу между установкой seed для NumPy и PyTorch.

**Требования**:
- Установите `np.random.seed(42)` и сгенерируйте массив 5x5
- Установите `torch.manual_seed(42)` и сгенерируйте тензор 5x5
- Запустите несколько раз и убедитесь, что каждая библиотека воспроизводима независимо

**Вопрос**: Будут ли результаты NumPy и PyTorch одинаковыми при одном seed?

### Задача 3: DataLoader с воспроизводимостью

Создайте DataLoader с воспроизводимым shuffle.

**Требования**:
- Создайте датасет из 100 случайных примеров
- Создайте DataLoader с `shuffle=True` и `generator` с фиксированным seed
- Запустите 2 раза и получите первый батч
- Убедитесь, что первые батчи идентичны

### Задача 4: Проверка инициализации весов

Проверьте, что веса модели инициализируются одинаково при установке seed.

**Требования**:
- Создайте `nn.Linear(100, 50)` дважды с одним seed
- Сравните веса обеих моделей
- Используйте `torch.allclose()` для сравнения

## 🟡 Средний уровень

Реализуйте функцию `setup_reproducibility(seed, device, deterministic)`.

**Требования**:
- Установка seed для Python random, NumPy, PyTorch CPU и GPU
- Настройка cuDNN (`deterministic` и `benchmark`)
- Установка environment variables
- Возврат информации о конфигурации в виде dict

**Бонус**: Добавьте проверку, что все настройки применились корректно.

### Задача 6: Воспроизводимый training loop

Напишите полностью воспроизводимый цикл обучения для простой модели.

**Требования**:
- Фиксация seed для: данных, модели, DataLoader
- Обучение на 3 эпохах
- Запустите обучение 2 раза с одним seed
- Убедитесь, что финальные веса моделей идентичны
- Логируйте loss на каждой эпохе для сравнения

### Задача 7: Тест воспроизводимости на GPU

Создайте тест, проверяющий воспроизводимость на GPU (если доступен).

**Требования**:
- Функция `test_gpu_reproducibility(seed, runs=3)`
- Запускает обучение модели N раз с одним seed
- Сравнивает финальные loss и weights
- Выводит, воспроизводимы ли результаты
- Измеряет максимальное отклонение между запусками

### Задача 8: Сравнение deterministic vs non-deterministic

Сравните скорость и воспроизводимость двух режимов.

**Требования**:
- Обучите модель с `deterministic=True` 10 эпох
- Обучите модель с `deterministic=False` 10 эпох
- Измерьте время обучения в обоих случаях
- Проверьте воспроизводимость результатов
- Постройте график: время vs детерминизм

## 🔴 Продвинутый уровень

### Задача 9: Система логирования экспериментов

Создайте систему для логирования всей информации о воспроизводимости.

**Требования**:
1. **Config класс** с параметрами эксперимента
2. **Функция save_experiment_info()** сохраняет:
   - Все параметры (seed, learning_rate, etc.)
   - Версии библиотек (PyTorch, NumPy, CUDA)
   - Git commit hash (если в git репозитории)
   - Timestamp
   - Финальные метрики
3. **Функция load_and_reproduce()** загружает config и воспроизводит результаты
4. Формат: JSON или YAML

**Бонус**: Добавьте автоматическую проверку, что воспроизведенные результаты совпадают с оригинальными.

### Задача 10: Multi-GPU воспроизводимость

Реализуйте воспроизводимое обучение на нескольких GPU (требуется multi-GPU система).

**Требования**:
- Используйте `DistributedDataParallel` или `DataParallel`
- Установите seed для каждой GPU (seed + rank)
- Обучите модель
- Запустите 2 раза и сравните результаты
- Убедитесь, что результаты воспроизводимы

### Задача 11: Инструмент проверки воспроизводимости

Создайте CLI-инструмент для автоматической проверки воспроизводимости проекта.

**Требования**:
```bash
python check_reproducibility.py --config config.yaml --runs 3
```

Инструмент должен:
1. Загрузить конфигурацию
2. Запустить обучение N раз
3. Сравнить результаты (loss, accuracy, weights)
4. Вывести отчет:
   - ✓ Полностью воспроизводимо
   - ⚠ Частично воспроизводимо (небольшие отличия)
   - ✗ Невоспроизводимо
5. Сохранить детальный отчет в HTML/PDF

### Задача 12: Анализ источников недетерминизма

Создайте инструмент для выявления операций, нарушающих детерминизм.

**Требования**:
- Monkey-patch случайных операций PyTorch
- Отслеживайте все вызовы random операций
- Логируйте, какие операции были недетерминированными
- Выведите список проблемных мест в коде
- Предложите исправления

**Пример вывода**:
```
Found 3 potential sources of non-determinism:
1. Line 45: torch.randn() called without setting seed
2. Line 67: DataLoader with num_workers=4 and no worker_init_fn
3. Line 89: cuDNN benchmark mode enabled
```

### Задача 13: Docker + seed воспроизводимость

Создайте Docker setup для полностью воспроизводимых экспериментов.

**Требования**:
- `Dockerfile` с фиксированными версиями всех зависимостей
- `requirements.txt` с точными версиями (используйте `pip freeze`)
- Environment variables для seed
- `docker-compose.yml` для запуска
- Скрипт `run_experiment.sh` который:
  - Строит контейнер
  - Запускает обучение
  - Сохраняет результаты
  - Проверяет воспроизводимость

**Тест**: Запустите контейнер на разных машинах и убедитесь, что результаты идентичны.

### Задача 14: Воспроизводимость с аугментацией

Реализуйте воспроизводимую аугментацию данных.

**Требования**:
- Используйте `torchvision.transforms` или `albumentations`
- Сделайте аугментацию воспроизводимой (фиксация seed)
- Проверьте, что одна и та же картинка аугментируется одинаково
- Убедитесь, что при обучении батчи аугментируются одинаково между запусками

**Усложнение**: Реализуйте систему, где аугментация воспроизводима, но меняется каждую эпоху предсказуемым образом.

### Задача 15: A/B тестирование моделей

Создайте систему для честного A/B тестирования двух моделей.

**Требования**:
- Функция `compare_models(model_A, model_B, num_runs=10, seed=42)`
- Обучает обе модели N раз с разными seed (42, 43, 44, ...)
- Собирает статистику (mean, std, min, max) для метрик
- Проводит статистический тест (t-test)
- Определяет, есть ли значимая разница между моделями
- Визуализирует результаты (boxplot, violin plot)

**Формат вывода**:
```
Model A: Accuracy = 0.85 ± 0.02
Model B: Accuracy = 0.87 ± 0.01
t-statistic: 3.24, p-value: 0.008
Conclusion: Model B significantly better (p < 0.01)
```

### Задача 16: Reproducibility Best Practices Checker

Создайте статический анализатор кода для проверки best practices воспроизводимости.

**Требования**:
- Сканирует Python файлы в проекте
- Проверяет:
  - Есть ли вызов `set_seed()` в начале скрипта
  - Используется ли `generator` в DataLoader
  - Установлены ли cuDNN флаги
  - Есть ли логирование seed в экспериментах
  - Версии зависимостей зафиксированы в requirements.txt
- Выводит отчет с рекомендациями
- Поддерживает разные уровни строгости (strict / normal / relaxed)

**CLI**:
```bash
python check_best_practices.py --path ./src --level strict
```
