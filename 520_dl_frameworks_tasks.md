## Задача 3: Миграция кода между фреймворками

**Цель:** Практика перевода кода из одного фреймворка в другой.

**Задание:**
Дан код модели на PyTorch:

```python
class TextClassifier(nn.Module):
    def __init__(self, vocab_size, embed_dim, num_classes):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        self.lstm = nn.LSTM(embed_dim, 128, batch_first=True)
        self.fc = nn.Linear(128, num_classes)
    
    def forward(self, x):
        x = self.embedding(x)
        _, (hidden, _) = self.lstm(x)
        x = self.fc(hidden.squeeze(0))
        return x
```

Реализуйте аналогичную модель в:
1. TensorFlow/Keras (Functional API)
2. JAX + Flax

**Проверка:** Убедитесь, что количество параметров совпадает.
